## 1. 问题与方案（头头拍板）

**现状**：`src/App.tsx` 把 8 个面板**单页平铺**（渠道 / Copilot / 保险库 / Client Key / 模型目录 / 熔断 / 用量 / 签到），
外加「网关状态」「快速开始」「当前范围」三张说明卡片 → 首屏被占满、找功能靠纵向滚动、无位置感。

**拍板结果（4 组）**：

| tab | 归入面板 | 语义 |
|---|---|---|
| **接入** | 渠道 · 模型目录 · Copilot 反代 | 把渠道/上游接进来 |
| **凭证** | 加密保险库 · Client Key | 保管密钥与本地口令 |
| **运维** | 熔断状态 · 用量统计 | 运行期的健康与花费 |
| **签到与积分** | 签到面板（含 T25 站点目录） | 自动签到与积分 |

（Copilot 归「接入」；WorkBuddy 落地后并入同组，**不新增 tab**。）

---

## 2. 做了什么

| 文件 | 内容 |
|---|---|
| `src/tabs.ts`（**新**，约 120 行） | **纯数据**的分组定义（`TABS` / `TabDef` / `PanelId`）+ `resolveTab`（未知值回落默认 tab）+ `readStoredTab` / `storeTab`（**无 localStorage 也不炸**）+ `tabOfPanel` |
| `src/App.tsx` | 顶栏（标题 + **网关状态常驻条**）+ **tab 栏** + **只渲染当前 tab 的面板** + 「快速开始」移入「接入」组首卡 + 「当前范围」移入底部 `<details>` 折叠区 |
| `src/App.css` | `.tabs` / `.tab` / `.tab.active` / `.statusbar` / `.header` 改为 flex / `details summary` 样式 |
| `src/tabs.test.ts`（**新**） | 6 条单测：分组顺序、**每个面板只归一个组且 8 个一个不少**、分组内容、功能域归属、**未知值回落**、无 localStorage 时读写不报错 |

**四条实现口径（02 §6.7）**：

1. 分组定义是**纯数据** → 可单测，不与 React 耦合；
2. **一次只渲染当前 tab 的面板**（不做「全渲染 + CSS 隐藏」）→ 首屏 DOM 显著变小；
3. **网关状态常驻顶栏**——切到任何 tab 都看得见「网关在不在跑」；
4. **选中项持久化**（`localStorage` 键 `llm-router.activeTab`）→ 重开应用回到原地；**未知值回落默认 tab**。

## 3. 判据逐条实测（5 条全绿）

### 判据① 4 个 tab 可切换，**每个 tab 只渲染自己的面板** ✅

- 单测（`src/tabs.test.ts`）：`TABS` 的 id 顺序 = `["access","credentials","ops","checkin"]`；标签 = 「接入 / 凭证 / 运维 / 签到与积分」；
  **8 个面板每个恰好归一个组、一个不少**（`seen.size == 8`）；
- 真机（截图 `docs/reviews/app-ui-t26-tabs.png`）：停在「接入」组时，页面上**只有**「快速开始」+「渠道」面板，
  **保险库 / Client Key / 模型目录 / Copilot / 熔断 / 用量 / 签到面板都不在 DOM 里**；
  另一张（`docs/reviews/app-ui-t25-catalog.png`）停在「签到与积分」组时，页面上**只有**签到面板。

### 判据② 切 tab 后**刷新应用仍在同一个 tab** ✅

- 真机实测观察：把选中项持久化后**重启应用，界面仍停在上次那一组**（多轮抓图过程中反复出现「改了默认组也不生效」的现象——正是持久化在起作用）；
- 未知值回落：`resolveTab(null | undefined | "" | "nope")` → 默认 tab（单测断言）。

### 判据③ **网关状态在任意 tab 都可见**（顶栏常驻） ✅

真机截图：两组界面顶部都显示「**● 运行中**　`127.0.0.1:8787`　`http://127.0.0.1:8787/v1`」。

### 判据④ 「快速开始」在「接入」组、「当前范围」在底部折叠区 ✅

真机截图：「接入」组首卡即「快速开始（从零接入三步）」，且文案已改成引用「凭证」组 / 「接入」组；
「当前范围」移到底部 `<details>`（折叠）。

### 判据⑤ 前端单测 + `npm run build` 通过 ✅

前端 **71/71**（原有 57 + 本卡 6 + T25 8）；`npm run build` → **38 modules / gzip 69.24 kB**（上一轮 35 modules / 65.84 kB，新增的是 tab 与站点目录两块）。

## 5. 边界（守住没做）

- **不加路由库**（单页 tab 用 `useState` 即可）、**不引第三方依赖**、**不改任何面板内部逻辑**（只改「谁被渲染」）；
- 「当前范围」只是折叠，**没删内容**；
- 面板间联动（`src/panels/bus.ts`）与轮询兜底**未动**。

---

## 6. 已知限制（留档）

1. **tab 状态只在单窗口内**——多窗口打开的第二个实例各自记自己的选中项（localStorage 是同源的，理论上会互相覆盖；当前未做多窗口协调）。
2. **tab 是单选**，没有「全部展开」的旧视图——需要看全部面板时逐个切（或后续加「全部」组）。
3. 面板**首次渲染**仍会各自拉一次数据（切 tab 时重新挂载组件 → 重新取数）；切 tab 的开销与原单页一致，**没有做缓存**。
